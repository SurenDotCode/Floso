# 🔗 Floso — AI Context Switcher Extension

**Floso** is a lightweight, privacy-focused Chrome extension designed to seamlessly capture and inject conversation context across **Claude**, **ChatGPT**, and **Gemini**.

---

## ✨ Features

* **Cross-Platform Capture:** Save full conversation logs from `claude.ai`, `chatgpt.com`, and `gemini.google.com`.
* **Smart Auto-Scroll Collector:** Handles virtualized long chats, stitching together complete message threads cleanly.
* **Context Injection:** Paste saved conversation capsules directly into another AI tool's input box without manual copy-pasting.
* **100% Local & Private:** No tracking, no external servers. All data stays in your browser's local storage (`chrome.storage.local`).
* **Clean Premium UI:** Sleek dashboard dark mode with site-specific visual badges and smooth hover highlights.

---

## 🚀 How to Install Locally (Developer Mode)

1. **Clone or Download** this repository to your machine.
2. Open your browser and navigate to `chrome://extensions` (or `brave://extensions`).
3. Toggle **Developer mode** ON (top right corner).
4. Click **Load unpacked** (top left corner).
5. Select the root folder containing the extension files.
6. Pin **Floso** to your toolbar and start capturing!
